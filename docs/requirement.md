# LLM 时间线可视化项目需求

## 目标
收集主流公司大模型版本发布时间和类别信息，最终做成可视化视频或图表。

## 信息范围

### 公司
OpenAI、千问（阿里）、Gemini（Google）、Grok（xAI）、Anthropic、Meta、DeepSeek、字节跳动（豆包）、百度（文心）、讯飞（星火）、MiniMax、阶跃星辰、Moonshot（Kimi）、Stability AI 等主流公司

### 模型类别
- 文本 LLM（首要收集）
- 多模态
- 视频生成
- 图片生成
- 语音模型

### 收集字段
**必填：**
- [x] 准确发布时间（精确到日）
- [x] 开源/闭源

**可选/后续：**
- [ ] 参数量
- [ ] 大中小杯分布（蒸馏版本）
- [ ] GitHub / HuggingFace Star 数量变化
- [ ] 价格（含活动价/默认价）

## 输出形式

### 1. 数据集
JSON/CSV 格式，结构化存储所有收集到的模型信息

### 2. 可视化
- **视频**：选择某系列模型（如 GPT 系列），按时间顺序播放从诞生到最新版本，配合时间轴动画
- **图表**：时间轴总览图，展示所有模型发布时间节点

## 视频具体要求
- 从 GPT-1 开始呈现模型发布时间节点
- 选择某个系列后，按时间顺序播放：首次诞生 → 版本迭代 → 最新版本
- 做成时间轴动画形式

## 原则
以效率最高为准，**先找现成资料，不轻易写爬虫**
